# ditl — Declarație fiscală ITL 002 в браузере

Форма с валидацией для декларации **ITL 002** (Model 2016, Anexa nr. 2) — налог на
здания юридических лиц, DGITL Sector 2 București. Данные печатаются поверх
оригинального незаполняемого бланка, готовый PDF можно посмотреть и скачать.

- Всё выполняется в браузере: нет backend'а, базы данных и аналитики.
- Данные никуда не отправляются — в production-сборке это закреплено CSP
  (`connect-src 'self'`, `form-action 'none'`, см. `vite.config.ts`).
- PDF собирается локально (pdf-lib), показывается в предпросмотре и скачивается через `Blob`.

Стек: React + TypeScript + Zod (через react-hook-form) + pdf-lib, Vite, Vitest. Хостинг — GitHub Pages.

## Окружение

```sh
direnv allow        # или: nix develop
npm install
npm run dev         # http://localhost:5173
```

| Команда           | Что делает                                   |
| ----------------- | -------------------------------------------- |
| `npm run dev`     | dev-сервер                                   |
| `npm test`        | тесты валидаторов, схемы, PDF и формы (jsdom) |
| `npm run build`   | проверка типов + сборка в `dist/`            |
| `npm run preview` | локальный просмотр production-сборки (с CSP) |

## Как устроено

```
src/
  form/validators.ts    CUI, CNP (контрольные цифры), суммы в леях, диакритика ș/ț
  form/schema.ts        Zod-схема декларации: поля, обязательность, межполевые правила
  form/fields.tsx       поля формы, адресный блок с автозаполнением
  form/sections.tsx     сворачиваемые разделы: статус, сводка, автосворачивание
  form/sample.ts        тестовые данные (кнопка в dev-режиме и с ?debug)
  pdf/layout.ts         где на бланке печатать каждое значение (координаты ячеек)
  pdf/generate.ts       pdf-lib: бланк + шрифт + отрисовка, отладочная сетка
  App.tsx               форма по разделам бланка I–IV
  PdfPreview.tsx        предпросмотр перед скачиванием
  assets/templates/     itl002.pdf — оригинальный бланк
  assets/fonts/         Liberation Sans (OFL), метрически совместим с Arial бланка
```

### Разделы формы

Форма сплошная, разделена на блоки по бланку (I–IV, приложения, декларация,
административные данные). У каждого заголовка — статус: «De completat»,
«N câmpuri de corectat» или «✓ Gata». Раздел без ошибок сворачивается, когда фокус
переходит в другой раздел, и показывает сводку; кликом по заголовку его можно
открыть. Порядок заполнения не навязывается. При отправке с ошибками разделы
с ошибками раскрываются, фокус встаёт на первое ошибочное поле.

### Правила проверки

- **CUI** контрибуабила — с проверкой контрольной цифры; префикс `RO` и пробелы убираются.
  Для юрлица код фискальной идентификации совпадает с CUI, поэтому он печатается
  в обе строки бланка («Codul de identificare fiscală» и «Codul unic de identificare»).
- **Împuternicit** (раздел II) — необязателен; если отмечен, нужны имя, фамилия
  и CNP или CUI (тоже с контрольной цифрой).
- **Cod poștal** — 6 цифр, если страна — România.
- **Comunicare exclusiv prin e-mail: DA** требует адрес почты.
- **Индикаторы стоимости (раздел IV)**: показываются и печатаются только колонки,
  подходящие типу здания (rezidențial / nerezidențial / обе для mixtă); нужна хотя бы
  одна стоимость, и у каждой стоимости — дата документа.
- Суммы принимаются как `1.250.000,50`, `1250000.50`, `1 250 000` и печатаются
  в румынском формате.
- Текст нормализуется: NFC, `ş/ţ` с седилью → `ș/ț` с запятой.
- Если значение не помещается в ячейку даже после уменьшения шрифта — PDF не
  создаётся, пользователь видит, какое поле сократить.

Не заполняются (остаются для руки): подписи и блок «persoană agreată» для
контрибуабила, который не может читать или писать.

## Настройка разметки

Координаты в `src/pdf/layout.ts` — границы ячеек таблицы, снятые с бланка
(pt, отсчёт от левого верхнего угла). Чтобы проверить или поправить их, откройте
`http://localhost:5173/?debug`, включите «Suprapune grila…» и сделайте предпросмотр:
поверх бланка будут сетка 10 pt и зелёные рамки всех полей.

Если ведомство выпустит новую версию бланка, замените `src/assets/templates/itl002.pdf`
и снимите координаты заново, например:

```sh
nix shell nixpkgs#poppler-utils -c pdftotext -bbox-layout itl002.pdf -
```

## Деплой на GitHub Pages

В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
Workflow `.github/workflows/deploy.yml` на каждый push в `main` прогоняет тесты,
собирает и публикует `dist/`. `base: './'` в Vite — сборка работает под любым
именем репозитория.
